# Contributing

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Keep `SKILL.md` concise and place detailed art-direction guidance in `references/`.
3. Do not add source photographs or other assets unless you have permission to redistribute them.
4. Run the Codex skill validator before opening a pull request:

   ```bash
   python /path/to/skill-creator/scripts/quick_validate.py photo-to-organic-knit
   ```

5. Explain the behavior change and include a non-sensitive test example when useful.

By contributing, you agree that your contribution is licensed under the MIT License.
